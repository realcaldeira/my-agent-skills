Output language: pt-BR. Canonical terms stay in English (manifest, ref, clone,
monorepo) with the Portuguese equivalent on first use.

```markdown
## <Conceito>

**Definição:** <paráfrase fiel da referência carregada — ex. `clone-plan.md`>

**Por que importa:** <o problema que resolve — 2–3 frases>

**Quando usar:**
- <bullets curtos>

**Quando NÃO usar / sinais de má aplicação:**
- <bullets>

**Exemplo:**
<exemplo curto e genérico — paths `.agent/clonedeps/...`, sem nomes de
harness, agentes ou projetos reais>

**Relaciona-se com:** <outros conceitos deste skill — referências>

**Aprofundar:** <referência deste skill>

**Fontes:** <tags usadas — ex. `[manifest]`, `[git ls-remote]`, `[repo docs]`>
```

## Definition of Done

- [ ] Definition is backed by a loaded reference; nothing invented.
- [ ] "Quando NÃO usar" is present and concrete.
- [ ] Example is short and generic (no harness or agent names).
- [ ] Answer is direct — the concept first, no preamble.
- [ ] Output in pt-BR.
