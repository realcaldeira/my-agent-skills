# Template — Teaching card (`explain`)

Output language: pt-BR. Canonical terms stay in English with the Portuguese
equivalent on first use. Mirrors the DDD skill's teaching-card shape.

```markdown
## <Técnica>

**Definição:** <o que é a técnica — 2–3 frases, com a fonte, ex. `[Osmani]`>

**Por que importa:** <o problema de legibilidade/complexidade que resolve>

**Quando usar:**
- <bullets curtos — os sinais correspondentes>

**Quando NÃO usar / sinais de má aplicação:**
- <bullets — as exceções de princípios.md: comportamento não entendido, código de performance, nomes que carregam significado, etc.>

**Antes / depois:** <pseudocódigo curto, sem framework — versão anterior e versão simplificada>

**Preservação de comportamento:** <as 4 perguntas de paridade como se aplica a esta técnica>

**Relaciona-se com:** <técnicas vizinhas — links para as referências>

**Aprofundar:** `references/simplification-signals.md` / `references/principles.md`

**Fontes:** <tags usadas>
```

## Definition of Done

- [ ] Definição cita uma fonte do vocabulário; nenhuma citação ou capítulo inventado.
- [ ] "Quando NÃO usar" presente e concreto (não genérico).
- [ ] Antes/depois curto e agnóstico de stack.
- [ ] Resposta direta — a técnica primeiro, sem preâmbulo.
- [ ] Saída em pt-BR.
